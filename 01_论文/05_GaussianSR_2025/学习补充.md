# GaussianSR 零基础学习补充

本文件是编者的中文学习说明，不属于论文原文，也不代表作者做过下列教学实验。相应内容同时附在 [完整中英对照版](../../PUBLICATION_SCOPE.md) 文末。证据以该文件的页码和 S/F/T/E 编号为准。

## 建议阅读顺序

先看图 1 和图 2，把流程记成“提特征 → 选高斯 → 连续场 → 查询 → 输出颜色”。再看 S025、公式 E005 与图 3，理解 LR 初始化和核选择。之后看图 4，理解为何必须省显存。最后看表 1—6 以及 S043 的限制。第一次阅读可暂缓三维背景公式 E001/E002；它们说明灵感来源，二维方法的核心是 E003—E005。

## 专有名词与前置知识

|---|---|---|---|
| Super-resolution, SR | 超分辨率 | 由少量像素生成更多像素的图像；目标是尽可能接近真实高分辨率图像。生成更多格点不等于凭空获得确定的真实细节。 | S002 |
| Arbitrary-scale super-resolution, ASSR | 任意倍率超分辨率 | 同一个模型可以输出多种倍率，包含 2.4、3.3 等非整数倍率。并不意味着无限大倍率仍有可靠质量保证。 | S013、T002 |
| LR / HR | 低分辨率 / 高分辨率 | 相对本次任务而言像素较少或较多的图像。训练时常由 HR 下采样得到 LR。 | S029 |
| Implicit neural representation, INR | 隐式神经表示 | 把信号看成可以在坐标处查询的函数。网络参数和特征共同决定函数值，而不是只保存一张固定大小的输出像素表。 | S002、S010 |
| Latent code | 潜在编码 | 网络提取出的隐藏特征向量；其中的分量不是人类预先命名的“眼睛”“边缘”等标签。 | S003 |
| Encoder / Decoder | 编码器 / 解码器 | 编码器从图像提取特征；解码器把特征变成输出的 RGB 值。本论文并没有取消解码器。 | S024、F002 |
| MLP | 多层感知机 | 若干全连接层组成的神经网络；通过可训练权重把输入向量映射为输出向量。 | S002 |
| Feature map / channel | 特征图 / 通道 | 可把一张特征图看成许多层“测量表”叠在一起；每层是一个通道。通道数不等于图像宽高。 | F004 |
| Query coordinate | 查询坐标 | 想要输出颜色的目标位置，可以在 LR 像素之间。连续表示允许询问这个位置的值。 | S024 |

| Mean / amplitude | 均值（中心）/ 振幅 | 中心决定高斯在什么位置，振幅决定其贡献的尺度；本方法用 LR 特征坐标和值初始化它们。 | S025 |
| Opacity / alpha blending | 不透明度 / alpha 混合 | 以权重控制一个基元的贡献。式 E004 调制特征值；式 E005 将多个场的贡献相加。 | S021、E004/E005 |
| Gaussian bank | 高斯库 | 共享的一组可学习高斯核参数。本实验默认 100 类；每个像素选择一个类别，不是整张图只有 100 个像素位置。 | S027、T006 |
| Logits | 未归一化分类分数 | 分类器对不同类别的打分，分数不是概率；经过 softmax 一类操作才可变成归一化权重。 | S027 |
| Gumbel Softmax | Gumbel Softmax 可微类别选择 | 训练时用软的类别权重近似离散选择，使梯度可传播；本文推理时改用硬选择。这里不另行补造论文未给出的采样公式。 | F003、S027 |
| Receptive field | 感受野 | 某个输出受到哪些输入区域影响。高斯范围及场的重叠改变特征聚合方式。 | S006 |
| Dual-Stream Feature Decoupling | 双流特征解耦 | 沿通道分两路：少量通道做较贵的高斯上采样，其余通道做便宜的双三次上采样，再融合。 | F004、S028、T005 |
| Unfolding / folding | 特征展开 / 折叠 | 重排张量的组织方式。本文用它们降低高斯处理的空间分辨率，再恢复布局；不能简单理解成复制整幅图。 | S028 |
| Bicubic interpolation | 双三次插值 | 按周围像素计算新位置值的一种固定插值方法。它无需训练，但不会凭任务学习复杂的纹理先验。 | S029、F012 |
| End-to-end / backpropagation | 端到端 / 反向传播 | 根据最终输出误差，计算并更新整条可微流程中相关参数。不是每个模块都必须人工分别训练。 | S001、F003 |
| Epoch / mini-batch / learning rate | 训练轮次 / 小批次 / 学习率 | 一轮涉及对训练集的遍历；小批次是一次更新使用的样本组；学习率调节参数更新步幅。 | S030 |
| L1 loss | 绝对误差损失 | 比较预测值和真实值的绝对差。原文给了名称，没有单独列出其归一化公式，所以这里不假定具体 reduction 设置。 | S030 |
| PSNR / dB | 峰值信噪比 / 分贝 | 衡量像素误差的常用指标，通常越大越好；它不完全等同于人眼偏好，也不能独自证明细节真实。 | T001—T006 |
| Ablation study | 消融研究 | 控制其他设置，改变某个模块或参数，查看性能如何变化。比只展示最终模型更有助于判断组件作用。 | S034—S036 |
| Generalization | 泛化 | 模型面对未用于训练的图像或数据集仍能工作。本文主要评估双三次合成退化，不等于覆盖所有真实退化。 | S029、S031 |
| Sparsity / CUDA | 稀疏性 / CUDA | 稀疏性指大量贡献可忽略或实现中为零；CUDA 是编写 NVIDIA GPU 计算程序的工具体系。高斯数学上通常有无限尾部，数值实现的局部支持需要另外区分。 | S043 |

### 前置知识 1：像素网格与连续函数

一张宽 64、高 48 的 RGB 图像包含 3072 个位置，每个位置有三个颜色数值。若放大到 2.5 倍，目标尺寸可为 160×120，总位置数变成 19200，是原来的 6.25 倍。倍率作用于两个空间维度，不能把像素数量误算为只增加 2.5 倍。

离散网格只在一些固定位置保存数值；连续表示描述“在其他位置怎么求值”。但可求值仅解决表示问题，输出是否接近真实细节仍依赖输入信息、训练数据、模型能力及评价条件。

### 前置知识 2：向量、矩阵和张量

一个像素位置的特征可用向量表示，例如 64 个数。整张特征图再加批次维度，常写成“批次 × 通道 × 高 × 宽”。矩阵是二维数组；张量是这种多维数组概念的推广。图 4 的双流是在通道维度切分，通常不会把一张图的左半边与右半边送入不同分支。

协方差矩阵描述高斯的形状。原文式 E003 使用逆矩阵，因此实现上必须关注可逆性。仅检查半正定还可能遇到奇异矩阵；不要将算法 A001 的短伪代码直接当作已经完备的数值实现。

### 前置知识 3：特征场怎样合成结果

阅读 E004 和 E005 时，可以先把“高斯函数值”看成某个场在查询点的影响权重，把不透明度调制后的特征看成要被加权的信息。然后逐个相乘、相加。实际输出往往仍是多通道特征，后面的解码器才产生 RGB。

三维背景公式 E002 含按深度排序的累乘项；二维核心公式 E005 是加权求和。二者结构不同，不应只因都叫“alpha blending”而互相替换。

### 前置知识 4：训练、推理与实验比较

训练阶段知道目标 HR 图像，可以计算误差并反向传播。推理阶段使用已训练参数输出图像，不再借助当前测试图像的真值更新模型。图 3 的“软”与“硬”描述类别选择方式的变化。

表中结果是作者报告的实验，不是本项目已复现的结果。比较方法时应同时关注数据集、倍率、退化方式、编码器、训练步数、设备与输出尺寸。本文排除了 CiaoSR 的直接数值比较，因此不能据此得出全面胜过 CiaoSR 的结论。

## 有解答的算例

### 算例 1：连续倍率与计算量

题目：输入是 64×64 的 RGB 图像，目标倍率分别为 2、4、6。目标尺寸和像素数各是多少？

解答：2 倍得到 128×128，共 16384 个像素；4 倍得到 256×256，共 65536 个像素；6 倍得到 384×384，共 147456 个像素。相对输入的像素数倍率分别是 4、16、36。表 T003 正好比较这三种目标尺寸，但实际耗时不会严格按这三个比例增加，因为实现包含固定开销、不同算子及并行效应。

易错点：把边长倍率当成面积倍率；或用一个尺寸的耗时推广全部尺寸。

### 算例 2：按论文 E005 做一次求和

题目：只考察一个特征通道。给定三个高斯场在某查询点的函数值为 0.6、0.3、0.1，经过 E004 调制后的特征值分别为 2、4、1，按 E005 求输出。

解答：三个贡献分别为 0.6×2=1.2、0.3×4=1.2、0.1×1=0.1；求和得到 2.5。这里的数值是教学假设，不是从论文实验中测得。

易错点：E005 并未写额外的“除以权重总和”。本例权重恰好和为 1 只是人为选择，不能因此给原式增加归一化操作；2.5 也是特征值，不一定已经是最终归一化 RGB。

### 算例 3：理解 8/64 通道的高斯分支

题目：编码器输出 64 个通道，默认 8 个通道进入高斯分支。两个分支分别占多少？

解答：高斯分支为 8/64=12.5%，双三次分支为 56/64=87.5%。这是通道比例，不是模型参数量比例，也不是精确的显存占用比例。表 T005 的默认版本为 Bicubic-56, Gaussian-8。

易错点：说“仅 12.5% 的像素接受高斯处理”；每个空间位置仍可能拥有这 8 个高斯分支通道。

### 算例 4：从耗时表得出有范围的结论

题目：表 T003 中，256×256 输出时 LIIF 为 43.18 ms，GaussianSR 为 41.70 ms；384×384 时分别为 86.43 ms 和 106.72 ms。应怎样描述？

解答：在该设备和设置下，256×256 时 GaussianSR 少用 1.48 ms，相对 LIIF 约减少 3.43%；384×384 时 GaussianSR 多用 20.29 ms，相对 LIIF 约增加 23.48%。因此“在某些输出尺寸较快”成立，“所有倍率均更快”不成立。这里仅是原表数值的算术分析，不是新跑出的基准测试。

## 自测与答案

1. **连续特征场是否证明输出细节一定真实？** 不。它保证表示可在连续位置求值；细节正确性需要真值或可靠评测验证。
2. **高斯库有 100 类，是否整幅图只使用 100 个高斯中心？** 不。库是共享核参数类别；各像素或特征点仍有其自身位置及特征贡献，见 S025、S027。
3. **GaussianSR 是否完全取消 MLP？** 不。S024 仍包含若干全连接层构成的解码处理。
4. **为什么训练时使用软标签？** 为让离散选择的近似形式可用于梯度优化；图 3 说明推理时转为硬选择。
5. **为什么不能把本文的二维与三维渲染公式完全等同？** E002 有深度顺序与透射率累乘，E005 没有该累乘项；使用情境不同。
6. **表 3 与表 4 到底哪张是耗时？** 按 PDF 表题，表 3 是耗时，表 4 是早期 PSNR。S033 的正文交叉引用写反，译文保留原话并明确指出。
7. **训练更早取得较好指标，是否严格证明用更少独立样本就同样有效？** 不能直接这样推断。它证明所报告训练阶段的性能比较；严格样本效率实验还应控制独立样本数量、训练更新次数等。
8. **仅让协方差对角项为正是否足够？** 不。整个矩阵还需要满足相应条件；半正定也未必可逆。论文短伪代码并未完整交代数值保障。
9. **看图 12 能否断定优于所有高倍率模型？** 不能。图 12 展示的是与双三次插值的选择性视觉比较。
10. **当前读完后，真正理解方法的最低标准是什么？** 能不看图复述两条分支，指出共享核参数与像素中心的区别，按 E005 手算一次贡献和，并能说明论文的显存限制及评测范围。
