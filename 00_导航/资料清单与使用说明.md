# 图像超分辨率资料清单与使用说明

> 2026-11-06目录已整理：[直接打开PDF原文副本](PDF%E5%8E%9F%E6%96%87%E7%B4%A2%E5%BC%95.md) · [新目录与启动说明](%E6%95%B4%E7%90%86%E5%90%8E%E7%9A%84%E7%9B%AE%E5%BD%95%E4%B8%8EPDF%E4%BD%8D%E7%BD%AE.md)。

这是一套面向零基础计科大学生的学习库，以LIIF为起点，重点覆盖任意倍率图像超分辨率中的连续表示、频率建模、注意力、神经算子与二维高斯表示。论文检索范围截至2026-10-29，清单核对日期为2026-10-30。

目前有**8篇论文、14个PDF附件、7份完整正文逐段中英对照、1份尚待补全文对照的中文导读**，另有基础教材、术语卡、阅读工作表和知识图谱。

14个PDF附件包括8份此前下载的正文版本、3份用户提供的会议版正文，以及3份独立补充材料；同一论文的不同版本归在同一Zotero条目下。

七份完整读本均提供英文原段与中文译段、原图表及中文图注、公式与来源页码、文末中文术语及前置知识、学习例题。英文参考书目保留原文。各目录中，**主要阅读`paper.md`**；`original.md`是自动提取底稿，`translation_notes.md`记录校订与来源问题，`source_map.json`保存段落和PDF位置的对应关系。

本轮补齐的LIIF、CiaoSR、SRNO分别有47、42、40段正文；它们的文末分别提供8、5、9道完整例题。其他读本同样有各自的学习附录，具体范围见各篇校订记录。

## 项目环境与工具

Obsidian仓库位于`LOCAL_VAULT`，论文PDF在项目`Zotero\data\storage`中，由项目专用Zotero分类“图像超分辨率”管理。根目录提供“打开项目Zotero.ps1”“打开Obsidian仓库.ps1”及对应快捷方式。

8个GitHub来源科研skills已按固定版本安装到项目：

| 功能 | Skills |
|---|---|
| 文献检索与引用整理 | literature-review、citation-management |
| Obsidian笔记和知识画布 | obsidian-markdown、json-canvas |
| 后续深度学习实验组织与日志 | pytorch-lightning、tensorboard |
| 统计分析和科学绘图 | statistical-analysis、matplotlib |

[默认规则](../PUBLICATION_SCOPE.md)已保存：所有研究资料留在项目；PDF必须真实归档到项目Zotero；MD放本仓库并建立关联；禁用LibreOffice；开启教学模式时记录每章重点和全部例题；额度可能中断时先写交接。技能安装与资料整理已经完成，尚未运行模型训练或基准复现实验。

## 当前缺口与使用顺序

ContinuousSR尚未完成全文对照，CiaoSR/SRNO独立SI尚未全文翻译，QuADA-GS SI尚未取得。LIIF未取得独立SI，LTE未发现官方独立SI。完整范围与检查证据见 [LIIF学习包交付验收](../PUBLICATION_SCOPE.md)；接续工作见 [交接](../PUBLICATION_SCOPE.md)。

建议先看零基础手册，再读LIIF。之后沿 **LIIF → LTE → GaussianSR → GSASR → QuADA-GS** 学习主线；CiaoSR和SRNO作为注意力、神经算子分支阅读，ContinuousSR先读现有导读。这个次序是教学安排，论文间的实际继承或引用关系以论文卡证据为准。
