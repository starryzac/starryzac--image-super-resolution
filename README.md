## 内容边界

保留自己的学习总结、术语、教材和例题，引用原始论文来源；排除论文全文、完整译文、论文截图和原始提取产物。部分本地图片或读本不在公开范围，相关链接会跳转到范围说明。内容主要为中文，中英切换适用于 README，正文尚未整体英译。
